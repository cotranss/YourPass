# YourPass — Генератор надёжных паролей

Школьный проект по информатике. Веб-приложение для создания и проверки надёжности паролей.

## Сайт
[https://cotranss.github.io/YourPass/](https://cotranss.github.io/YourPass/)

## Функции
- **Генератор паролей** — создаёт сложные пароли с настройкой длины и типов символов
- **Проверка надёжности** — оценивает пароль по 8 критериям безопасности
- **Ключевое слово** — можно добавить своё слово в пароль
- **Руководство** — рекомендации по созданию и хранению паролей

## Технологии
- HTML5, CSS3
- JavaScript (ES6+)
- GitHub Pages для хостинга

## Безопасность
Все операции выполняются **локально в вашем браузере**. Пароли не передаются на сервер и не сохраняются.
